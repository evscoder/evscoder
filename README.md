## How I work

1. **Understand the flow.** Map user actions, data requirements, loading states, validation, empty results and errors.
2. **Define the boundaries.** Separate UI, state and API responsibilities. Choose a rendering strategy that fits the product.
3. **Build the interface.** Create reusable components and predictable state transitions.
4. **Validate the result.** Check edge cases, loading performance, unnecessary renders and bundle size.
5. **Support the release.** Verify production behavior and document decisions that help other developers.
